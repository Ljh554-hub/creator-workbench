# 每日精选自动更新 · 详细操作教程

> **目标**：让「每日精选」每天早上 9 点**自动更新内容**，所有设备（电脑/平板/手机）看到的始终是最新数据。

---

## 一、整体原理（先理解再操作）

```
┌─────────────┐    每天 9:00     ┌──────────────────┐
│  GitHub      │ ──────────────→ │ autofeed/*.json   │
│  Actions     │   自动运行脚本   │ (podcast/express/ │
│  (定时任务)   │                 │  books.json)      │
└─────────────┘                 └────────┬─────────┘
                                         │ Raw URL
                                         ▼
                    ┌──────────────────────────────────────┐
                    │  所有设备（电脑/平板/手机）            │
                    │  统一从 https://raw.githubusercontent.com  │
                    │  /Ljh554-hub/creator-workbench/main/  │
                    │  autofeed/xxx.json 拉取最新内容         │
                    └──────────────────────────────────────┘
```

**关键点**：
- 数据只存在一个地方（GitHub 仓库），所有设备读同一个地址 → **永远一致**
- 不依赖 CloudStudio 部署更新文件 → 即使不重新部署，内容也会自动变新
- GitHub 免费账户完全够用，Actions 免费额度远超需求

## 二、详细步骤（按顺序操作）

### 第 1 步：在 GitHub 上创建仓库（如果还没有）

1. 打开 https://github.com/new
2. **Repository name** 填：`creator-workbench`
3. 选择 **Private**（私有，只有你自己能看到）
4. **不要勾选** "Add a README file"
5. 点击 **Create repository**

### 第 2 步：把工作台代码推送到 GitHub

打开你电脑上的终端（Git Bash / PowerShell），依次执行：

```bash
# 1. 进入工作台目录
cd C:\Users\29115\WorkBuddy\workbuddy-1\creator-workbench

# 2. 初始化 Git（如果是第一次）
git init

# 3. 添加所有文件到暂存区
git add .

# 4. 创建首次提交
git commit -m "🎉 创作工作台初始版本"

# 5. 设置远程仓库地址（把 Ljh554-hub 换成你的用户名）
git remote add origin https://github.com/Ljh554-hub/creator-workbench.git

# 6. 推送到 GitHub
git branch -M main
git push -u origin main
```

> 如果提示输入用户名密码：用户名填 `Ljh554-hub`，密码填你的 **Personal Access Token**（不是 GitHub 登录密码）
>
> **获取 Token 方法**：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Generate new token → 勾选 `repo` 权限 → 复制

### 第 3 步：确认关键文件已在仓库中

推送成功后，打开仓库页面 https://github.com/Ljh554-hub/creator-workbench ，应该能看到：

```
creator-workbench/
├── .github/workflows/daily-feed.yml   ← 定时任务配置（必须存在）
├── scripts/generate-feed.js            ← 内容生成脚本（必须存在）
├── autofeed/
│   ├── podcast.json
│   ├── express.json
│   └── books.json
├── index.html
├── sw.js
└── manifest.webmanifest
```

如果 `.github` 或 `scripts` 目录不存在或为空，说明本地文件没推上去——检查第 2 步是否成功。

### 第 4 步：启用 Actions 工作流

1. 打开仓库页面 → 点击顶部的 **Actions** 标签
2. 会看到 **"Daily Feed Update"** 工作流（黄色/灰色圆圈图标）
3. 点击它 → 进入详情页
4. 点击右侧 **"Enable workflow"** 按钮（如果显示的是 "Disable workflow" 说明已启用）

### 第 5 步：手动触发一次测试（验证是否正常）

1. 在同一页面左侧找到 **"Run workflow"** 下拉按钮
2. 确认分支是 **main**
3. 点击绿色 **"Run workflow"** 按钮
4. 几秒后下方会出现一条运行记录，点击进去看日志
5. 等待约 30 秒，看到 ✅ 绿色对勾 = 成功！

### 第 6 步：在工作台中设置数据源地址

1. 打开工作台（硬刷新 Ctrl+Shift+R 加载新版）
2. 侧栏底部点击 **🎨 样式** → 再点 **⚙ 工作台设置**
3. 找到 **「📡 每日精选数据源」** 输入框
4. 填入以下地址：

```
https://raw.githubusercontent.com/Ljh554-hub/creator-workbench/main/
```

5. 点击 **保存**

### 第 7 步：验证效果

1. 进入任意有「每日精选」的栏目（播客推荐 / 练嘴素材 / 读书推荐）
2. 点击 **🔄 刷新** 按钮
3. 应该看到内容更新了，状态栏显示 **"N 条"**（绿色徽章）
4. 每条精选现在都有 **「📖 查看详情」** 按钮 → 点击可查看完整内容弹窗

## 四、常见问题排查

### Q1：Actions 运行失败？
- 检查 `.github/workflows/daily-feed.yml` 文件是否在仓库根目录（注意路径层级正确）
- 检查是否有写入权限（Private 仓库需要 Settings → Actions → General → Allow all actions）

### Q2：工作台刷新后还是旧内容？
- 按 F12 打开开发者工具 → Console 面板看有没有红色报错
- 确认「⚙ 工作台设置」里的数据源地址末尾有 `/` 且没有拼写错误
- 尝试清除浏览器缓存后重试

### Q3：想修改精选内容池怎么办？
编辑仓库中的 `scripts/generate-feed.js`，修改 `PODCAST_POOL` / `EXPRESS_POOL` / `BOOKS_POOL` 数组即可。
改完后 commit + push，下次运行就会用新内容池。

### Q4：不想用 GitHub，只想 CloudStudio 本地更新？
把「⚙ 工作台设置」里的数据源地址**留空**即可回退到本地文件模式。
但这样每次更新需要你手动替换 `autofeed/*.json` 并重新部署。
